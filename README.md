# AGN Structure Function (AGNSF)

**AGNSF** is a C++ library with Python bindings for calculating structure functions of astronomical light curves.

> 🚧 **Work in progress.**  
> The project is currently under active development and is not yet ready for general use.

## Planned features

- Structure function (SF) calculation
- Ensemble structure function (ESF)
  - Pooled structure function analysis
- Monte Carlo uncertainty estimation
- Python interface through NumPy and pybind11
- Efficient zero-copy interface for large astronomical light curves
